Reelyard for macOS
================

Let macOS run the unsigned binary once:
    xattr -d com.apple.quarantine reelyard

Try it:
    ./reelyard serve
Then open http://localhost:8787 to create your account.

Start it now and at every login:
    sudo install -m 0755 reelyard /usr/local/bin/reelyard
    reelyard install --user && reelyard start --user

Install ffmpeg too (brew install ffmpeg) for language checks, thumbnails
and TV transcoding.
Other commands: reelyard status | stop | restart | uninstall | reset-password | version

Only download content you have the rights to.
